📖 后台使用帮助

调整过关时长

在「关卡过关时长」表里改数字 → 点 保存 即生效;点 恢复默认 可还原。玩家 下次进入游戏(开屏点开始)时拉取新时长,正在进行的一局不受影响。

看板图表怎么看

  • 漏斗(到达 vs 通过):两根柱差距越大 = 卡在这关、流失越多。
  • 各关通关率:越低越难。
  • 平均尝试次数:越高越容易卡(1 = 基本一次过)。
  • 剩余时间占比:偏高 = 时间给太多(可缩短);接近 0 = 时间很紧。
  • 综合难度分:绿色简单、红色难,一眼看出最难的关。

调参建议标签 → 对应动作

  • 合理 难度与时长合适,不用动
  • 偏松 玩家剩很多时间,可缩短时长(标签给参考秒数)
  • 偏紧 玩家常差一点,建议加时间
  • 偏难 失败完成度很低,加时作用小,考虑降低难度
  • 样本不足 数据太少,等更多玩家再判断

按时间段分析

右上角选「起 / 止」日期 → 应用,只看该时段数据;全部 看全部历史。改完时长后,过几天用"改之后"的日期段再看一次,可对比调整效果。
